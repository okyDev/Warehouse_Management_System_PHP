# Warehouse System

Este repositorio contiene un sistema web administrativo completo para el manejo de tiendas,
el sistema esta desarrolado en **PHP** 100% **Vanilla**, con un enfoque en las buenas practicas
y proteccion de los datos, el sistema esta pensado de manera local.

## Caracteristicas
- Gestion de usuarios/empleados, autenticacion, monitoreo y ajustes por medio de permisos.
- Gestion de permisos por roles y personalizado.
- Catalogo de productos y lotes, procesamiento de stocks bajos, categorias y aclamiento a proveedores.
- Log automatico.
- Sistema de cambio de divisas, y gestion de estas misma.
- Pagos flexibles por diferentes metodos y divisas.
- Visualizacion de datos de acciones.
- Configuraciones visuales y de sistema incluidas.
- Backup personalizados.
- Reportes extendos y variados, exportacion a pdf.
- Opciones especiales de seguridad ( Bloqueo de usuario, requisitos de clave, etc).
- Alertas globales y personalizadas.


## Tecnologias utilizadas
- **PHP 8** 
- **Apache PHP**
- **MySQL**


## Requisitos 

- **PHP 8 o superior**
- **MySQL**
